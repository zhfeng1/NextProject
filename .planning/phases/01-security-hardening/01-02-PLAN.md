## Goal

新增 `POST /api/v2/providers/verify-model` 端点，支持对已保存的 provider 的选定模型发送轻量级验证请求（"hi"），确认模型可用性。前端在每个已选模型旁添加"验证"按钮。Key 始终由后端从数据库解密读取，前端不传明文。

<threat_model>

### Assets
- **A1**: 用户 API Key（加密存储在数据库中，由 Plan 01 保护）
- **A2**: 第三方 API 调用配额

### Threats
| ID | Threat | Severity | Mitigation |
|----|--------|----------|------------|
| T1 | 验证端点被滥用消耗用户 API 配额 | LOW | `max_tokens=5` 最小请求；JWT 认证保护；用户手动触发 |
| T2 | 验证请求中 Key 通过日志泄露 | MEDIUM | 使用 `httpx.AsyncClient`，不记录请求 headers；后端从 DB 解密，不经过前端 |
| T3 | SSRF — base_url 指向内网地址 | MEDIUM | base_url 来自已保存的 provider（用户自己配置），不接受任意 URL；与现有 `fetch-models` 端点风险等级一致。**Accepted Risk**：当前部署在 Docker 网络中，容器间网络隔离已限制可达范围；对 base_url 的协议校验（仅允许 `https://` 和 `http://`）在 Task 2.1 中实现，内网地址过滤作为 Accepted Risk——原因：用户可能合法使用内网 Ollama/vLLM 等自部署模型服务，强制过滤内网地址会破坏核心功能 |

### Accepted Risks
- 用户可以通过反复点击验证按钮消耗自己的 API 配额（属用户自主行为）
- 用户配置的 base_url 可能指向内网地址（如 Ollama）——这是预期用途，与 `fetch-models` 端点风险一致

</threat_model>

```python
@router.post("/verify-model")
async def verify_model(
    payload: dict[str, Any] = Body(default_factory=dict),
    current_user: object = Depends(get_current_user),
    db: AsyncSession = Depends(get_db),
) -> dict[str, Any]:
    provider_id = (payload.get("provider_id") or "").strip()
    model = (payload.get("model") or "").strip()
    if not provider_id or not model:
        raise HTTPException(status_code=400, detail="provider_id and model are required")

    user_id = str(getattr(current_user, "id"))
    p = await db.get(UserLLMProvider, provider_id)
    if p is None or str(p.user_id) != user_id:
        raise HTTPException(status_code=404, detail="Provider not found")

    base_url = (p.base_url or "").strip().rstrip("/")

    # SSRF mitigation: only allow http(s) schemes
    if base_url and not base_url.startswith(("https://", "http://")):
        raise HTTPException(status_code=400, detail="base_url must use http or https protocol")

    api_key = decrypt_api_key(p.api_key) if p.api_key else ""
    fmt = p.format or "responses"

    try:
        async with httpx.AsyncClient(timeout=10) as client:
            if fmt == "messages":
                # Claude API
                resp = await client.post(
                    f"{base_url}/messages",
                    headers={
                        "x-api-key": api_key,
                        "anthropic-version": "2023-06-01",
                        "content-type": "application/json",
                    },
                    json={
                        "model": model,
                        "messages": [{"role": "user", "content": "hi"}],
                        "max_tokens": 5,
                    },
                )
            elif fmt == "responses":
                # OpenAI Responses API
                resp = await client.post(
                    f"{base_url}/responses",
                    headers={
                        "Authorization": f"Bearer {api_key}",
                        "content-type": "application/json",
                    },
                    json={
                        "model": model,
                        "input": "hi",
                        "max_output_tokens": 5,
                    },
                )
            else:
                # OpenAI Chat Completions API (fallback)
                resp = await client.post(
                    f"{base_url}/chat/completions",
                    headers={
                        "Authorization": f"Bearer {api_key}",
                        "content-type": "application/json",
                    },
                    json={
                        "model": model,
                        "messages": [{"role": "user", "content": "hi"}],
                        "max_tokens": 5,
                    },
                )
            resp.raise_for_status()
            return {"ok": True, "message": f"模型 {model} 连通正常"}
    except httpx.HTTPStatusError as exc:
        detail = ""
        try:
            detail = exc.response.json().get("error", {}).get("message", str(exc))
        except Exception:
            detail = exc.response.text[:200]
        return {"ok": False, "error": f"{exc.response.status_code}: {detail}"}
    except Exception as exc:
        return {"ok": False, "error": str(exc)}
```

注意：`decrypt_api_key` 已在 Plan 01 (task 1.3) 中 import，此处复用同一 import 行。

```typescript
async function verifyModel(p: ProviderUI, model: string) {
  p.verifying = model
  p.msg = ''
  try {
    const res = await providersAPI.verifyModel({ provider_id: p.id, model })
    p.msg = res.ok ? `${model}: 连通正常` : `${model}: ${res.error || '验证失败'}`
  } catch (e: any) {
    p.msg = `${model}: ${e?.response?.data?.detail || '验证失败'}`
  } finally {
    p.verifying = ''
  }
}
```
